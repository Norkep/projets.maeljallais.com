## Lire et publier

Ouvrir [Wiztivi](articles/wiztivi/index.html), [MAIF](articles/maif/index.html), [Toms](articles/toms/index.html) ou [Le futur du smartphone](articles/apple-watch/index.html) directement dans le navigateur. Aucun outil de génération ni installation de dépendances n’est nécessaire. La police Poppins est chargée depuis Google Fonts ; une police système prend le relais hors ligne.

Publication prévue sur GitHub Pages, depuis un dépôt public, sur le sous-domaine `projets.maeljallais.com` ; maeljallais.com reste sur Framer. Adresse d’une étude : `https://projets.maeljallais.com/articles/<slug>/` (compléments : `/articles/wiztivi/<slug>/`). Dans Framer, lier ces adresses. Le fichier `CNAME` contient le sous-domaine, `.nojekyll` conserve les pages telles quelles et le petit `index.html` racine redirige vers Framer.

Le dépôt Git est initialisé en local (branche `main`), sans dépôt distant. Reste à faire par le titulaire des comptes :

1. Créer le dépôt GitHub public et y pousser `main`.
2. **Settings > Pages > Deploy from a branch** : branche `main`, dossier `/(root)`.
3. Chez le registrar de maeljallais.com : enregistrement DNS `CNAME` `projets` -> `<compte>.github.io`.
4. **Settings > Pages > Custom domain** : `projets.maeljallais.com`, puis cocher **Enforce HTTPS** dès que le certificat est émis. Vérifier aussi le domaine dans les réglages Pages du compte GitHub pour éviter qu’un tiers le réutilise.

Indexation (19 novembre 2026) : les onze articles sont indexables avec `index, follow, noimageindex, max-image-preview:none`, une URL canonique absolue, Open Graph/Twitter et un JSON-LD (Person, WebPage, CreativeWork ou Article) sans aucune image. `robots.txt` bloque Googlebot-Image sur tout le site ; pour les autres robots, il bloque les dossiers `images/` et les extensions d’images, en laissant CSS et JS accessibles. `sitemap.xml` liste les onze URL, sans balise image. La redirection racine et `404.html` restent en `noindex`. Titres et descriptions réécrits après audit SEO ; textes Jalios au passé, période « 2025 – 2026 ».

Limite connue : dans un dépôt public, les images restent consultables et téléchargeables sur github.com (et raw.githubusercontent.com). `robots.txt` et `noimageindex` ne couvrent que le site publié, et GitHub Pages ne permet pas d’en-tête `X-Robots-Tag`. Publier Pages depuis un dépôt privé, possible avec un plan GitHub payant, supprimerait cet accès aux fichiers sources ; le site publié resterait public.

Les anciennes adresses sous `pages/` et `article.html?id=...` sont remplacées par cette structure.
